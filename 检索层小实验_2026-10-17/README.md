# 检索层小实验（2026-10-17）

主反馈见[给成员③的反馈](../CityU-AgenticRAG-小组作业-成员1集成/docs/反馈_成员3_检索层推进与技术选型_2026-10-17.md)。这里只放实验脚本、开发探针和机器结果。

## 输入与边界

- 只读取集成项目159篇语料，SHA-256：`2c3f9a2d9dc116062791e8c646ad7e343fd8e22f5a59c91581f84808b0620752`。生产库当前159活动文档、159 dirty、0 chunks。
- `实验结果.json`记录输入文件实验前后SHA一致；生命周期实验只在内存副本运行，未改生产数据、源码、数据库或项目虚拟环境。
- 本机项目环境和捆绑Python均无torch、sentence-transformers、BGE-M3本地权重。官方Hugging Face连接在普通及获准联网尝试中失败，镜像配置请求也未成功，因此没有取得真实tokenizer或模型。
- **计数为正则英文词／数字／标点代理单位，不能称BGE-M3 tokens。** 标题前缀与特殊token不在此计数预算中。
- **FAISS使用从447个文本块得到的1024维词法TF-IDF控制向量，不是BGE-M3 embedding。** 这能检查索引计算、保存加载、过滤顺序及数量级，不能验证多语言或语义模型优劣。
- 14个开发探针从本地语料选取，先定义后运行；结构V2根据V1失败补规则，属于开发内修正，没有独立验证集。完整片段覆盖是切块检查，不是问答或检索正确率。

## 实验内容

1. 6组切块：固定300/40、500/0、500/80、800/80，以及结构V1/V2。检查全部原文代理单位无遗漏，并统计块数、膨胀与14段关键关系覆盖。结构版按问题、日期、字段和费用表组织，短单元不强行重叠；超长单元回退滑窗。V2额外绑定Application Period等标签与紧随日期。规则仍是开发原型。
2. 词法控制向量：英文词／数字分词，简单停用词表，从文档频率2以上且低于80%的词中选频率最高1024词，按log TF × IDF编码后L2归一化；未进行模型推理。保存各探针top-5来源与完整证据命中，供排查评测定义。
3. FAISS：FlatIP与HNSWFlat（M=16、efConstruction=80、efSearch=32），1024维float32、单线程。分别构建并测试14个英文开发query；10次预热、100次单查询计时，计时不含编码、数据库与应用开销。HNSW与Flat一致仅对该组词法查询成立。Flat另与NumPy矩阵内积作正确性对照。
4. Windows中文路径：记录原生write_index报错；改用serialize_index／Python文件写入和deserialize_index后，检查重载ID和分数一致。
5. 元数据：实读topic／column取值，检查fees别名和admission签证来源；10向量合成例子检验先取top-5后过滤的漏检。
6. 生命周期：复制数据库到内存，模拟已建索引，为签证文档建测试chunk；导入人为移除该页的快照，检查inactive／dirty／残留chunk，再恢复原快照检查重新激活。未对FAISS执行同步删除，该部分仍需③实现。

## 文件与复现

| 文件 | 用途 |
|---|---|
| `run_experiments.py` | 语料审计、切块、词法控制、FAISS及过滤实验 |
| `lifecycle_experiment.py` | 用项目现有接收代码运行内存副本生命周期实验 |
| `开发探针.json` | 14题英文开发问题、原文片段、字符偏移及来源行号 |
| `实验结果.json` | 完整机器结果、版本和源文件SHA |
| `索引生命周期实验.json` | 移除及重新激活结果 |
| `切块样例.json` | 费用、签证、校历、FAQ和宿舍的切块样例 |
| `lexical_control_*.faiss`及映射 | 仅本实验的词法控制索引，不得作为BGE-M3索引发布 |
| `fixtures/` | 人为移除签证页的测试快照，绝非②修正版或正式交付语料 |
| `.deps/` | 隔离实验依赖，未写入项目虚拟环境 |

输入主项目路径由脚本相对本目录定位。在当前工作区根目录运行：

```powershell
& '[本机路径已省略] -X utf8 './检索层小实验_2026-10-17/run_experiments.py'
& './CityU-AgenticRAG-小组作业-成员1集成/.venv/Scripts/python.exe' -X utf8 './检索层小实验_2026-10-17/lifecycle_experiment.py'
```

FAISS实验用Python 3.12.14、NumPy 2.3.5、faiss-cpu 1.15.1。本次FAISS仅安装到`.deps/`；tokenizers也隔离安装但未参与计数，因为模型tokenizer文件未取得。换机器可单独建立实验环境安装上述NumPy／FAISS版本；生命周期脚本使用项目既有环境。重跑会覆盖本实验结果与控制索引，时间数字可能波动。

最早准备／修正脚本为本次操作记录；复现只需上面两个主实验脚本。BGE-M3真实参数与效果需由③另行补测，不能用本目录结果替代。
