## 三、data 索引文件如何生成

### 3.1 原始数据来源

原始语料由成员①②负责采集、清洗及导出，存放于：

`data/corpus.jsonl`

文件使用 JSONL 格式，每行保存一条网页记录，包含正文、URL、标题、主题、学年等信息。

成员③直接读取该文件，不使用旧版 `cityu_faq.db`。

### 3.2 构建流程

运行 `scripts/build_wsb_index.py` 后，程序自动执行：

1. 读取 `data/corpus.jsonl` 中的 158 条记录。
2. 调用 `chunk_records()` 进行网页清洗及文本切块。
3. 生成 862 个 Chunk，保留 URL、标题、Topic、Academic Year 等元数据。
4. 使用 `multilingual-e5-small` 将 Chunk 转换成 384 维向量。
5. 对向量进行归一化，建立 FAISS `IndexFlatIP` 索引。
6. 自动保存两个文件：
   - `data/wsb_index/index.faiss`
   - `data/wsb_index/chunks.json`

### 3.3 重新构建命令

在项目根目录运行：

`python -m scripts.build_wsb_index`

运行前需要安装依赖并在本地缓存 Embedding 模型。

**注意：** 目前两个文件均已生成并验证成功。如果原始语料及切块逻辑没有变化，不需要重新运行构建脚本。

重新构建会覆盖现有索引文件。

## 四、安装依赖及模型准备

在项目根目录运行：

`pip install -r requirements-wsb.txt`

依赖版本：

- `faiss-cpu==1.15.1`
- `sentence-transformers==6.1.0`
- `torch==2.14.1`
- `numpy==2.4.6`

Embedding 模型需要提前缓存到本地，因为检索器使用 `local_files_only=True` 加载模型。

Rerank 模型在第一次执行 `rerank=True` 时才加载。如果本地没有对应模型，需要具备访问 Hugging Face 的条件以完成下载。

模型文件不包含在 GitHub 交付代码中。

## 五、Retriever 调用接口

```python
from src.retriever import Retriever

retriever = Retriever()

hits = retriever.search(
    "How can students pay their tuition fees at CityUHK?",
    topic="学费与缴费",
    k=5,
    rerank=True
)

for hit in hits:
    print(hit.text, hit.url, hit.score)
```

### 参数说明

- `query`：用户输入的问题。
- `topic`：可选主题，默认 `None`，表示不限制主题。
- `k`：返回的结果数量，默认 5。
- `rerank`：是否执行二次排序，默认 `False`。

`search()` 返回 `list[Hit]`，每个 `Hit` 包含：

`chunk_id`、`doc_id`、`text`、`score`、`url`、`title`、`topic`、`academic_year`。

如果需要将检索结果传递给 Agent，可以使用 `dataclasses.asdict()` 转换为字典，再序列化为 JSON。

### 检索流程

用户问题 → E5 Embedding → FAISS 向量检索 → Topic 过滤 → 可选 Rerank → 返回 Top-K Chunk。

启用 Rerank 时，默认从至少 20 个候选 Chunk 中重新排序，再返回最终结果。

## 七、已知问题及注意事项

1. **中文跨语言检索：** 目前部分中文问题无法准确召回英文语料；成员⑤负责查询翻译及 Agent 路由，可优先尝试将问题翻译成英文后检索。
2. **语料覆盖：** 部分信息（例如图书馆具体开放时间）尚未在当前语料中找到。
3. **Rerank：** 只能对已召回的候选 Chunk 重新排序，无法找回未被初次检索召回的内容。
4. **运行路径：** 建议在项目根目录运行，使用默认相对索引路径。Windows 下包含中文的绝对路径可能导致 `faiss.read_index()` 失败。
5. **索引元数据：** `chunks.json` 尚未单独记录 `corpus_sha256`、`column` 和 `source`，但已在交接前验证语料版本和 Chunk 一致性。
6. **返回结构：** `search()` 返回 `Hit` 对象列表，不是字典列表。
7. **现有索引：** 无需重新构建，除非原始语料、切块逻辑或 Embedding 模型发生变化。
