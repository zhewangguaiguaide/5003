## ③如何开始

安装 Python 3.12，用项目 [requirements.txt](../requirements.txt) 与 [requirements-lock.txt](../requirements-lock.txt) 重建环境。接收方核对下面两项，不需要重新抓网站：

```powershell
Get-FileHash .\data\corpus.jsonl -Algorithm SHA256
.\.venv\Scripts\python.exe -m unittest discover -s tests -q
```

JSONL 使用 UTF-8，一行一条记录。读取示例：

```python
import json
from pathlib import Path

documents = [json.loads(line) for line in
             Path("data/corpus.jsonl").read_text(encoding="utf-8").splitlines()
             if line.strip()]
```

| 字段 | 检索层处理 |
|---|---|
| url、title、source | url 为规范化唯一来源；保留标题与域名，回答可追溯 |
| content | 官网原文正文，主要为英文；作为切块输入 |
| topic、column | 主题与采集栏目；均保留到 chunk 元数据 |
| academic_year | YYYY-YYYY 或空串；混合年份页面可能为空，需在切块时处理局部条件 |
| date、crawled_at | date 可能回退为采集时间；不能自动当作政策生效日 |
| image_urls、file_urls | JSONL 中是字符串数组，仅交付链接，未解析附件全文 |
| error | 合格语料中为空；不将失败审计作为可检索正文 |

## ③要交付什么

按[分工方案§5.2](分工与交接方案.md)实现 src/retriever.py（目前尚不存在）：

```python
@dataclass
class Hit:
    chunk_id: str
    doc_id: str
    text: str
    score: float
    url: str
    title: str
    topic: str
    academic_year: str

class Retriever:
    def search(self, query: str, topic: str | None = None, k: int = 5) -> list[Hit]: ...
    def list_topics(self) -> list[str]: ...
```

doc_id 对应来源文档 URL；检索不到返回空列表。上述为既定接口契约，不是已实现功能。

1. 先做切块，FAQ 优先按问答/标题划分，保留费用项目与数值、日期与事项、开放时间与地点的对应关系。切块结果不回写 corpus.jsonl。
2. 采用支持中英文的 embedding，完成批量向量化与向量索引，记录模型、chunk size、overlap 和输入 SHA。
3. 实现主题过滤与语义检索、rerank；无明确学年的页面保留召回渠道。
4. 如果使用①集成库，按 active、index_dirty、来源 SHA 重建或清理失效 chunk/向量；确认输入未变后才清除 dirty 状态。
5. 和④配合用20条已知答案问题验证 top-5 命中率≥70%。④负责指标、基线与消融；③负责检索实现。

签证核心页位于 admission，同时抵港服务在 visa_geo，不能只检索一个栏目。⑤负责查询翻译、中文回答、跨栏目路由和引用编排；这些功能尚未在本次语料交接中实施。
