## 3. 怎么验收

```text
python -m unittest tests.test_corpus tests.test_standard -v
python -m src.main --dry-run
python -m src.main --live --full --repair-loops 2
python -m src.main --export data/corpus.jsonl
python -m src.main --quality
python -m src.main --migrate
```

全量 live 抓取使用 `--full`：13 个种子优先采集，已有详情 URL 跳过但不终止扫描，详情尝试受栏目预算约束。默认不加 `--full` 仍保持原 Harness 增量终止语义。预算是上限，不代表成功页目标，更不代表全站穷尽。

导出命令会打印输入数、去重后的输出数，以及 URL/正文指纹分别去掉的数量。检索层只读取 `data/corpus.jsonl`，不应直接依赖 `.db` 文件。

## 4. 已知失败模式 / 坑

- 页面抓取失败：现象是详情页错误计数增加；判据是 `--repair-loops 1` 后仍留在错误列表；规避是保留错误 URL，人工复跑对应栏目，不把失败页伪装成空正文。
- WAF 挑战页：现象是 HTTP 200 但正文很短；判据由 `looks_like_challenge()` 判断；规避是使用 `stealthy` 模式并遵守 2–3 秒限速。
- 同一内容多 URL：现象是尾斜杠、片段或 `utm_*` URL 重复；规避是导出阶段 `canonicalize_url()` + 正文 SHA-256 指纹双重去重。
- `academic_year` 缺失：页面没有学年时保留空字符串，不猜测；有 `2026/27`、`2026-2027` 等文本时统一为 `2026-2027`。
- 项目 `.venv` 已于 2026-10-11 切换为 Python 3.12.10，安装 `requirements.txt` 全部依赖；优先使用 `.venv\Scripts\python.exe`。原 3.14 虚拟环境已删除。
