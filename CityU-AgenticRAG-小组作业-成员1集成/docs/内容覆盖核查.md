## 四、发现的问题与修复

1. **scholarship 种子页是 JS 壳**（正文仅 383 字："What's New"+cookie 提示）→ **已修复**：
   换种子为 `scholarships-prizes-at-a-glance`（HTML 116KB，正文 4,956 字）+ `financial-assistance/overview`（正文 1,750 字）；
   include 从 `/sds/` 收窄到 `/sds/student-life-resources/student-finance`（否则 104 个发现链接里的就业/体育/选举页会吃掉预算）。
   注：旧链 `scholarships-prizes` 已 404（302 → /error/404）。
2. **`/scholarship/` 独立奖学金站是 SPA**：79KB HTML 但正文只有 "Loading..." 骨架 → 不可作种子，仅记录。
3. **探针脚本曾误报 library 同栏目链接=0**：系探针自身把 host 型 include 拿去匹配 path 所致；
   爬虫本体（crawler.py）对**完整 URL** 做子串匹配，library 栏目工作正常。探针已修正重跑。
