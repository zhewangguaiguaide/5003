# 成员2返工增量包（2026-10-11）

本包用于覆盖已有 CityU-AgenticRAG 项目，不是完整独立项目。保留原目录结构，将 src、tests、docs、data 等目录合入接收方已有项目。覆盖前备份同名文件；若接收方已修改同一文件，请对比合并。

## 包含内容

- 本轮修改：src/corpus.py、crawler.py、parser.py、fetcher.py、storage.py、db.py、main.py；tests/test_acceptance_repairs.py、test_db.py；requirements.txt、requirements-lock.txt；README.md；两份成员2交接/返工文档。
- 配套文件：src/config.py、config.yaml、schema.sql、tests/test_corpus.py、.gitignore。它们用于保证早期原型也具备当前字段配置、数据库 schema 和质检测试，不代表本轮全部重新修改。
- 最新数据：data/corpus.jsonl（159 条）、data/quality_report.json（13/13 种子覆盖）、data/crawl_audit.jsonl（采集审计）。审计文件为本机累计记录，以配置中的八个栏目为正式采集证据。
- 不包含虚拟环境、浏览器缓存、SQLite 数据库、API 密钥及其他未修改模块。

## 接收方操作

安装 Python 3.12，在原项目根目录运行：

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m unittest discover -s tests -q
```

对应项目基线的预期测试结果为 35 项通过；如接收方另有新增测试，总数会变化。
需要浏览器抓取时另运行 `.venv\Scripts\scrapling.exe install`；仅使用已交付语料或运行离线测试无需下载浏览器。

成员③直接使用 data/corpus.jsonl 开发检索层。data/quality_report.json 是本次采集快照，不依赖接收方数据库。
本包不携带 .db；接收方空数据库下运行 --status/--quality 不会自动显示本次采集结果，--export 会按接收方自己的数据库重新生成语料，不应在未导入/抓取时覆盖交付的 corpus.jsonl。

需要重新采集时：

```powershell
.venv\Scripts\python.exe -m src.main --live --full --mode http --repair-loops 2
.venv\Scripts\python.exe -m src.main --export data/corpus.jsonl
.venv\Scripts\python.exe -m src.main --quality
.venv\Scripts\python.exe -m src.main --migrate
```

本次验证使用 HTTP 模式；若接收方网络返回 WAF 挑战，可改用 --mode stealthy。预算扫描和种子覆盖不表示全站递归穷尽，详见 docs/返工核查报告_成员2_语料质检.md。
